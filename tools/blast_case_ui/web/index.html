1เลือกโมเดล

โมเดลที่กำลังใช้: ยังไม่ได้เลือกไฟล์

ระบบจะตรวจรอยขาด ซ่อมรูเล็ก ตั้ง Domain และ Mesh ให้ก่อน โดยไม่แก้ไฟล์ต้นฉบับ

เลือกไฟล์ แล้วกด “ตรวจ ซ่อม และตั้งค่า Auto”
ตัวเลือกไฟล์และการซ่อมเพิ่มเติม
ผลตรวจเชิงเทคนิค
ยังไม่มีข้อมูล

4เวลา จุดวัด และค่าคำนวณ

5ตรวจและสร้างหลาย Case

ต้องเลือกตำแหน่งก่อนสร้าง Case · ระบบจะสร้างโฟลเดอร์ย่อยตามชื่อ Case และไม่เขียนทับ

เลือกโฟลเดอร์หลัก ตั้งชื่อ Case แล้วจึงตรวจและสร้าง
LOCAL CASE LIBRARYยังไม่ได้เลือกโฟลเดอร์
Case ที่สร้างแล้วจะแสดงที่นี่

6เชื่อม SSH Server

ยังไม่ทดสอบ
Mac WebUI→SSH Server→Docker→blastFoam

ใช้ SSH port ของ Ubuntu ปกติคือ 22 · Password จะไม่ถูกบันทึก หลังตั้งค่าครั้งแรกระบบจะใช้ SSH key

SSH private key
กรอก IP และชื่อผู้ใช้ แล้วกด “ทดสอบ Server”

7เชื่อม Docker และตรวจ blastFoam

ยังไม่ทดสอบ

ระบบเชื่อม Docker ผ่าน SSH Server โดยตรง · พอร์ต 18080 → 8080 เป็นพอร์ต Web ภายใน Container ไม่ใช่พอร์ตเชื่อม Docker

ตัวเลือก Docker เพิ่มเติม
ยังไม่ได้อ่าน Docker บน Server
เมื่อ Server เชื่อมแล้ว กด “ทดสอบ Docker”
